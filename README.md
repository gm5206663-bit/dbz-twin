# The Twin

One public project for Gohan and Goshin’s story. The current selected manuscript runs through **Chapter 46**. The selected revisions and continuations are review drafts, not automatically accepted; the separately accepted earlier Chapter 20 is preserved in the research archive.

Start with [Chapter One — Two Names](The%20Twin/chapters/Chapter_01_Two_Names.md), the [project guide](The%20Twin/README.md), or [workshop start page](WORKSHOP.md). The [research library](Research/README.md) and [Sara continuity](Sara/README.md) are included, as are the workshop manifest and retained 291-episode caption source ZIP. The author corrected an earlier privacy assumption and wants the work public; historical references to owner-only access describe past checkpoints.

This is a snapshot of working files, not automatic synchronization or reader acceptance. Source captions, short synopses and selected references do not establish a complete audiovisual review. [Earlier backup versions](https://drive.google.com/drive/folders/19UbKNgXtv_64NfAl4RhHDkgUBdVVMMpZ) are readable by anyone with the link. Git history preserves repository commits, not every earlier Drive archive.

The GitHub copy retains its repository landing page, `.gitattributes` and `RESEARCH.sha256`, which do not exist in the local workshop. Its `WORKSHOP_MANIFEST.sha256` is therefore resealed for the repository’s actual file inventory rather than byte-identical to the local workshop manifest. Project, caption-index, Sara and workshop checks can be run from the repository root.
